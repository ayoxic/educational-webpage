# 🎓 INSEA Institutional Website

A full-stack institutional web platform developed for **INSEA (Institut National de Statistique et d'Économie Appliquée)**.
This project combines a modern user interface with a structured backend system for academic management.

---

## 🚀 Features

* 🌍 **Bilingual Interface** (French 🇫🇷 / Arabic 🇲🇦)
* 🎨 **Responsive Design** (desktop & mobile friendly)
* 🧑‍🎓 **Student Management System**
* 📚 **Modules & Academic Structure**
* 📅 **Schedule & Timetable Management**
* 📊 **Evaluation & Grades System**
* 📩 **Contact Form with Database Integration**
* ⚡ **Optimized Performance & Clean UI**

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Tools:** VS Code, XAMPP

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/ayoxic/educational-webpage.git
```

2. Move the project to:

```
C:\xampp\htdocs\
```

3. Start **Apache** and **MySQL** using XAMPP

4. Import the database:

* Open phpMyAdmin
* Create database: `insea_site`
* Import your SQL file

5. Run the project:

```
http://localhost/insea
```
